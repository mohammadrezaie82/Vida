# Daily Planner App

![Project Preview](./public/preview.png)

## About The Project

Daily Planner App is a modern productivity and daily management application built with Vue 3 and Vite. Users can create an account, manage daily tasks, set deadlines and reminders, check the daily weather, and organize their schedule in a clean and user-friendly dashboard.

The application is designed to help users stay productive and manage their daily activities more efficiently.

---

## Features

- User Authentication
- Daily Weather Information
- Task & Deadline Management
- Reminder System
- Calendar Integration
- Multi-language Support
- Responsive Dashboard UI
- User Settings Management

---
